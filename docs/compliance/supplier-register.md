# Supplier register

| Supplier | Service | Data involved | DPA / terms |
|----------|---------|---------------|-------------|
| Supabase | DB, Auth, Storage | All app data | Supabase DPA / ToS |
| Vercel | Hosting | Request logs, env | Vercel terms |
| Stripe | Payments | Customer, subscription, invoices | Stripe services agreement |
| Firebase (optional) | Push | Device tokens | Google terms |
| Microsoft | Calendar OAuth | Tokens, calendar metadata | Microsoft terms |
| Google | Sign-in / Maps | Auth / location queries | Google terms |
| GitHub | Source control | Code (no live customer DB) | GitHub terms |

Review supplier security pages annually or on major plan changes.
